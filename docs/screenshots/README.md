# Storefront Screenshots Guide

Before pushing to GitHub, start the app locally (`npm run dev`), open `http://localhost:3000`, and capture full-page screenshots at `1440x900` into this folder:

- `01-storefront-hero.png` — Multi-department hero and quick-jump cards
- `02-departments-grid.png` — Separate sections for Dresses, Fruits, Vegetables, Groceries, Shoes, and Cosmetics
- `03-product-detail.png` — Product detail modal with size/weight/shade selector
- `04-checkout-cod.png` — Bag drawer & Cash on Delivery checkout
- `05-seller-admin.png` — Seller Admin inventory & order fulfillment view
